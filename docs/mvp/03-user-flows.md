# User Flows

## Flow 1: Baseline Full Mock

Goal:

- Establish Edward's current level.

Steps:

1. Open the app.
2. Select `Full Mock`.
3. Select `Exam Mode`.
4. Click `Start`.
5. Answer all 21 questions.
6. Mark confidence for uncertain questions.
7. Submit before timer ends.
8. Review score.
9. Review topic breakdown.
10. Review wrong answers, especially wrong-and-confident answers.
11. Write down weakest topic.
12. Start a Topic Drill for weakest topic.

Expected outcome:

- Edward knows his baseline score and weakest topics.

## Flow 2: Learning With Practice Mode

Goal:

- Learn concepts quickly without waiting until the end.

Steps:

1. Open the app.
2. Select `Topic Drill`.
3. Choose topic, for example `A/B Testing`.
4. Select `Practice Mode`.
5. Click `Start`.
6. Answer a question.
7. Mark confidence.
8. Immediately read explanation.
9. Continue until the drill is complete.
10. Review final summary.

Expected outcome:

- Edward learns the concept behind each question immediately.

## Flow 3: Timed Topic Drill

Goal:

- Improve speed and accuracy in one weak topic.

Steps:

1. Open the app.
2. Select `Topic Drill`.
3. Pick weakest topic from last result.
4. Select `Exam Mode`.
5. Start drill.
6. Answer all questions under timer.
7. Submit.
8. Review mistakes.

Expected outcome:

- Edward improves one topic with realistic pressure.

## Flow 4: Review Last Attempts

Goal:

- See whether practice is improving performance.

Steps:

1. Open the app.
2. View recent attempts.
3. Compare recent scores.
4. Identify repeated weak topics.
5. Start a relevant drill.

Expected outcome:

- Edward can decide what to practice next without a complex dashboard.

## Flow 5: Framework Refresh

Goal:

- Memorize practical PM mental models.

Steps:

1. Open Frameworks page.
2. Read A/B testing checklist.
3. Read funnel diagnosis checklist.
4. Read cohort retention checklist.
5. Return to app.
6. Start mock or drill.

Expected outcome:

- Edward applies frameworks while answering questions.

## Flow 6: exam day Morning Warmup

Goal:

- Warm up without exhausting mental energy.

Steps:

1. Open app.
2. Select `Topic Drill`.
3. Choose weakest topic or random mixed set if available.
4. Select `Practice Mode`.
5. Answer 10 questions maximum.
6. Review explanations.
7. Read Frameworks page.
8. Stop heavy practice 2 to 3 hours before interview.

Expected outcome:

- Edward enters the interview calm and primed.
